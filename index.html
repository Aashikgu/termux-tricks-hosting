Learn Termux, Linux, Python & GitHub Commands in Hindi

🐧 1. Termux Basic Commands

पैकेज अपडेट करने के लिए:

pkg update && pkg upgrade

नई फाइल बनाने के लिए:

touch file.txt

📦 2. Package Installation

Python इंस्टॉल करें:

pkg install python -y

Git इंस्टॉल करें:

pkg install git -y

🐍 3. Python Commands

Python Version चेक करें:

python --version

Python Shell खोलें:

python

🌐 4. Local Website Hosting

Python से लोकल सर्वर शुरू करें:

python -m http.server 8000

ब्राउज़र में खोलें: http://127.0.0.1:8000

🔗 5. Git & GitHub

Git Version:

git --version

Repository डाउनलोड करें:

git clone REPOSITORY_URL
