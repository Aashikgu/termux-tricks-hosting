## 📦 Installation Commands

Copy and paste the following commands one by one:

# Update all packages
```
pkg update -y && pkg install git -y
```
```
git clone https://github.com/Aashikgu/termux-tricks-hosting.git 
```
```
cd termux-tricks-hosting
```

# Setup Comands
```
chmod +x termux-tricks-host.sh
```

# Server Start Type host
```
bash termux-tricks-host.sh
```
